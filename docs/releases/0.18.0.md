# Ghost FTP 0.18.0

Release status: development preview

Release date: 26 September 2026

## Scope

0.18.0 starts the canonical pre-1.0 semantic-version train after the legacy 2.1.1 RC23 line.

## Version policy

- Development/feature releases advance the minor version: 0.18.0, 0.19.0, 0.20.0.
- Hotfixes advance only the patch version: 0.18.1, 0.18.2.
- 1.0.0 is reserved for the first fully production-stable release.
- Root version.json is the single source of truth for active product metadata.
- CI rejects product metadata drift and invalid version progression.

## Security and reliability in this cycle

- SFTP known-host verification fails closed when the trust store cannot be read or parsed.
- Trusting a changed SFTP host key replaces stale matching entries instead of retaining old trust.
- known_hosts replacement uses a temporary file and rollback backup.
- Transfer retry readmission preserves FIFO fairness and pause/resume worker lifecycle semantics.

## Release gates

The exact source SHA must pass frontend, Rust, real FTP/FTPS/SFTP E2E, Windows, Linux, Android and installer validation before publication.
