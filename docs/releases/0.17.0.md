# Ghost FTP 0.17.0

Release date: 25 September 2026

## Scope

0.17.0 is an all-platform production-hardening release candidate for Ghost FTP. It covers the Windows app, Linux app, Android app and public website in the same release train.

## Platforms

- Windows x64 portable executable.
- Windows x64 setup executable.
- Linux x86_64 binary.
- Linux x86_64 AppImage.
- Linux amd64 DEB package.
- Linux x86_64 RPM package.
- Android APK.
- Website, source, update templates, documentation and SHA-256 checksum bundles.

## Windows and Linux

- Bumped desktop package metadata to `0.17.0`.
- Bumped Tauri bundle metadata to `0.17.0`.
- Bumped Rust GUI package metadata to `0.17.0`.
- Bumped Ghost FTP CLI package metadata to `0.17.0`.
- Bumped Ghost FTP agent protocol and daemon package metadata to `0.17.0`.
- Kept the native build gate for Windows and Linux release artifacts.
- Kept the quality gate for TypeScript, i18n, UI contracts, Go tooling, Rust check, Rust tests and Clippy.

## Android

- Bumped Android release metadata to `0.17.0`.
- Bumped Android Gradle version to `versionCode 211023` and `versionName 0.17.0`.
- Kept real FTP, explicit FTPS and SFTP actions for listing, download, upload, delete and remote folder creation.
- Kept mobile transfer safety UX: guarded upload, root/dot-segment delete protection, bounded activity log, lifecycle-safe UI updates and Android document picker upload.
- Disabled Android password view-state persistence and clear the password on disconnect and Activity destruction.
- Locked FTP and explicit FTPS production behavior: connect/default/data timeouts, login validation, passive mode, binary transfers and cleanup.
- Locked explicit FTPS `PBSZ 0` and protected data channel `PROT P`.
- Locked SFTP SHA-256 host-key fingerprint verification, strict host-key checking, connection timeouts and cleanup.

## Website

- Added `/support/` with installation, verification, safe connection and issue-reporting guidance.
- Updated `website/sitemap.xml` with the new production routes.
- Uses the reviewed native Windows QA screenshot as the product visual; no stock, AI-generated or placeholder app image.
- Removed missing scene-image references and fake animated release percentages.

## Update channel

## Release gates

0.17.0 must not be considered published until all of these pass for the same source commit:

- Ghost FTP quality.
- Ghost FTP protocol E2E.
- Ghost FTP native build 0.17.0.
- Ghost FTP Android.
- Ghost FTP 0.17.0 release packaging.
